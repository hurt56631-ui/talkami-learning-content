# HSK 3.0 缅文谐音补齐审计（2026-11-06）

| 级别 | 词数 | 原有谐音 | 本次新增 |
| --- | ---: | ---: | ---: |
| HSK 3.0 一级 | 300 | 300 | 0 |
| HSK 3.0 二级 | 200 | 0 | 200 |
| HSK 3.0 三级 | 500 | 0 | 500 |

本次只向 `content/words/packs/hsk2_3_0.json`、`hsk3_3_0.json`、`hsk4_3_0.json` 的词目增加 `phonetic_my`，不改 `id`、`hanzi`、`pinyin`、`burmese`、`examples`、`level`，不增加搭配或音频。HSK 一级原有 300 条保持不变；16 个实用分类 4500 条已有谐音，保持不变。

## 生成来源与检查

- 以 16 个实用分类的 4500 条 `pinyin` / `phonetic_my` 配对为参照，按词条中文和去声调拼音匹配，**1235 条直接复用**。
- 另外 **459 条**根据已有中文字/拼音音节对照组合缅文注音，按词内标准拼音约束音节划分；遇到未知单字时参考项目已有谐音音节习惯。
- 对 **6 条特殊读音**单独补充：得（děi）、俩（liǎ）、嗯（ǹg）、森林（sēnlín）、熟（shú/shóu）、帅（shuài）。
- 程序检查 1700 条新增注音非空、包含缅文字母、无拉丁字母或数字，音节数量与词条汉字（考虑儿化）对应。
- 跨 4 级检查各词包数量与原 ID 范围：1–300、301–500、501–1000、1001–2000，总共 **2000 条**，ID 均唯一。
- 新增 `scripts/check_hsk_3_0_phonetics.py`，并纳入 PR/主分支 GitHub Actions 的词库检查。

## 边界与发布

缅语谐音只是普通话的**近似助记**，不表示完整声调、卷舌或儿化；这批生成注音已通过结构和程序一致性检查，**尚无缅语母语教师逐条试听签核**，请以标准拼音与中文录音为准。

这次变更仅更新 HSK 3.0 源词包。当前 `content/words/catalog.json` 的正式 HSK 目录仍是旧版 HSK1–3 600 词；如果 App 需要显示这批 HSK 3.0 词包，需要单独完成目录接入与 Release 发布，合并 GitHub 源代码本身不会自动改变已发布的 App 数据。
