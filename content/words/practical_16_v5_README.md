# Talkami 实用中缅 V5：16 分类

参考本仓库 HSK1–HSK4 3.0 词包规范，将用户上传的 V4 四列词典转换为单词 JSON 包。

**结构审计**：4500 个词目，16 大类、163 小类。中文、拼音、缅文近似注音、缅语释义原样保留；ID 使用 1000001–1004500 以避免与 HSK 原 ID 冲突。26 条主题归类调整（可查看 audit）。

**已复用 HSK 内容**：1490 个严格拼音匹配的词条有各 2 组中缅搭配与 2 条例句，共 2980 组搭配与 2980 条例句。

**待补充内容**：3010 条没有可靠配套内容，`collocations` 和 `examples` 等字段为空，`content_status: "needs_collocations_examples"`；完整 2+2 仍需新增 6020 组搭配和 6020 条例句。不能视为已写完全部 4500 条。

**拼音差异**：14 条同字形但拼音无法严格对应，未自动复用 HSK 例句，请核查 audit。缅文注音为辅助，普通话发音以拼音和标准音频为准；缅语释义尚未得到母语教师逐条终审。

## JSON 格式

每一类在 `content/words/packs/practical_16_v5/category_XX.json` 中，顶层是与 HSK 文件相同的词条数组。字段包含 `id`, `hanzi`, `pinyin`, `phonetic_my`, `burmese`, `collocations`, `collocations_pinyin`, `collocations_my`, `collocation_ids`, `examples`, `level`，并加上分类和审核状态。

`level: "practical"` 并不是 HSK 官方等级；`hsk_reference_level` 只表明匹配了本仓库的 HSK 3.0 包。
