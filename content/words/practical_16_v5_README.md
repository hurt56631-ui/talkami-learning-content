# Talkami 实用中缅词典 V5 · 16 分类 / 4500 词 / 无例句与搭配

本分支为精简草稿，尚未合并 `main`。按仓库 HSK 单词 JSON 结构保存中文、拼音、缅文近似注音、缅语释义、唯一 ID、分类。

## 内容规模
- **4500** 条完整词目、**16** 个大类、**163** 个小类。
- 每条数据有独立稳定 ID **1000001–1004500**；`id=1000000+source_order`，排序和改分类不会改变 ID。
- 每条均有中文、拼音、缅文近似注音、缅语释义；缅文注音仅辅助，不代替标准中文音频。
- **4500 条全部没有搭配、例句内容**；为尽量兼容原 HSK 词卡组件，保留字段 `collocations:[]`、`collocations_pinyin:[]`、`collocations_my:[]`、`collocation_ids:{}`、`examples:[]`；`content_status:"dictionary_only"`。
- 词条本身的中文发音可按 1 词 1 音频准备，不需要对搭配和例句做配音；音频文件需要应用端另行生成，本 PR 没有生成音频。
- 保留 PR #15 的 26 条主题归类优化，不删词。

## 翻译质量与差异
- 原 V4 已经提供全部 4500 条缅语释义，这里不是凭空重译。
- 核对 HSK1–4 的参考词目及原词典后，完成 **6** 处拼音修正，**8** 处多义词/常用义补充；全部列在 `practical_16_v5_audit.json`。
- 音调变体、地区差异与存在多种合理读法的词不擅自更改。
- **尚未完成缅语母语教师对 4500 条逐一终审**，因此不可保证译文零错误；正式发布前建议复核高风险、多义词及实际 TTS 读音。
