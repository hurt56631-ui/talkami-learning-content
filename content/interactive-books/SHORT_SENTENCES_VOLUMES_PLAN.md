# 《短句数据.zip》拟分册方案（草稿，尚未上架）

本计划只针对 2026-10-09 提供的 `短句数据.zip`，不将它误认为完整的六十个主题。

## 审核结论

- 压缩包内部有 **40 个主题 ZIP**，对应 **38 个不同主题**（08 和 13 有重复版本）。
- 按“优先完整整主题 JSON，否则选择每小课最新完整 JSON”的口径去重后，有 **32 个含完整短句的主题、122 个小课、2140 个主句**。
- 07—12 六个主题只有补丁/复核文件，**未提供完整的主句母本**，不能直接作为教材出版。
- 2140 句均有中文、缅文释义及使用说明，但无完整主句拼音、缅文谐音和 breakdown 拆解；发布前需根据产品教学标准补齐并校对。这不同于已经完成发音字段的《服装厂中文1000句》。

## 为什么不建议合成一本

初学者通常按场景找短句，不会按两千多句的总列表查找。五册有明确封面和购买入口，支持逐本定价、不同用户需求，并复用统一的 VIP 权限。也不建议把38个主题拆成38本，内容碎片太多、书架和商品管理都会变复杂。

## 技术发布原则

1. **没有补齐关键教学字段前，只存草稿目录，不把这些内容写入公开的线上 `catalog.json`**，也不售卖标记为“已完成”的书。
2. 完整主题与课次一对多：整主题 JSON 中的 lesson ID/phrase ID 必须保持对应；不能把“整主题 JSON”和“单课 JSON”再次叠加计数。
3. 发布时每本含公开封面、目录、免费试学文件和版本化 ZIP；在线按小课读卡，ZIP 下载作为额外选项。
4. 不因上传一本新书再改后端商品常量，但新的通用书籍阅读器、数据规范和 API 内容路径要统一。
5. 书架标题沿用“实用中文口语”，图片封面下只显示册名。
