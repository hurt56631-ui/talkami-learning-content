# 新版口语60主题（独立草稿目录）

本目录是逐主题重新审校的**中缅实用口语候选数据**，不会自动替换网站线上旧版的 `packs/01.json`、`packs/02.json` 或 `catalog.json`。网站正式启用需另行接入新版读取逻辑与权限机制。

| 主题 | 主句 | 回复 | 类似说法 | 中缅说明 | 配音合计 |
|---|---:|---:|---:|---:|---:|
| 01.01 问候寒暄 | 111 | 98 | 50 | 16 | 259 |
| 01.02 感谢道歉 | 78 | 66 | 45 | 16 | 189 |

每个主题采用固定文件命名：

- `01.01.json` / `01.02.json`：完整主句、按需添加的回复、类似说法与简短双语说明。
- `01.01.txt` / `01.02.txt`：主句配音，每行 `ID｜中文｜缅语`。
- `01.01_extras_tts.txt` / `01.02_extras_tts.txt`：补充回复与类似说法配音，独立ID（如 `01.02.01-S001_reply01`）。
- `01.01_校验说明.md` / `01.02_校验说明.md`：计数和审校状态。

所有主题的主句ID固定；不为凑数强制加入回复、类似说法或说明。中缅说明只显示文字、不纳入配音。JSON已做基础结构检查，仍需要缅语母语教师最终审校和真实设备音频试听。
