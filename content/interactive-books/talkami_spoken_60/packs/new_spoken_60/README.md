## 主要文件
- `XX.XX.json`：现行结构化主句、少量有用回复、类似说法和双语说明；主句按实用性优先排序。
- `XX.XX.txt`：主句配音源，当前主句ID保持不变。
- `XX.XX_extras_tts.txt`：更新后的回复与类似说法配音源。
- `XX.XX_audio_manifest.json`：本主题完整配音ID；`AUDIO_MANIFEST_01_10.json`：01组2331条配音ID。
- `XX.XX_id_remap.json`：此前重排的旧新主句ID对照；`XX.XX_reply_pruning_20261111.json`：本轮删除的回复ID及内容。
- `REPLY_EDITORIAL_RULES_20261111.json`：逐场景回复保留/删除规则。
- `QUALITY_REVIEW_20261111_REPLY_PRUNING.md`：最新审核总结。更早审核报告中旧数量仅作历史参考。
