每个主题采用固定文件命名：

- `01.XX.json`：完整主句、按需添加的回复、类似说法与双语说明。
- `01.XX.txt`：只包含主句配音，每行 `ID｜中文｜缅语`。
- `01.XX_extras_tts.txt`：补充回复和类似说法配音，各有独立ID。
- `01.XX_校验说明.md`：计数、质量校验、已知局限和发布状态。

主句ID稳定；不为凑数强制加回复、类似说法或说明。中缅说明只显示文字，不纳入配音。JSON已完成基础结构与数量检查，正式发布前仍需缅语母语审校和音频试听。
