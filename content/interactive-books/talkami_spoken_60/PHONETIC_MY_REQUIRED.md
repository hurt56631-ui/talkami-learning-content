# Talkami 缅文谐音必填标准

2026-10-11。第47、48主题开始实施。

- **每一张主卡必须同时有 `pinyin` 和 `phonetic_my`，两者均不可留空；不允许以罗马拼音填充缅文谐音。**
- `pinyin` 使用带调的标准汉语拼音，并按真实中文语境检查多音字及常见变调；`phonetic_my` 是便于零基础缅甸学生模仿的缅文字母**近似读音辅助**。
- `phonetic_my` 按主句的汉语发音逐音节标注（空格分隔），与拼音音节数保持一致；禁用机器翻译成缅语句意代替谐音。
- **缅文近似音无法完整表达普通话四声、卷舌、送气及部分元音差异**：始终同时显示带调拼音并配合普通话真人/TTS朗读，谐音不应取代它们。
- 未来主题 JSON 发布校验：主卡100%具有两个字段，缅文谐音使用缅文字母、没有无声调的伪拼音，音节对齐；不符合条件禁止发布。
- 这批主题按186个去声调音节的缅文近似写法一致输出，仅保证程序对齐与文字可读，**不代表缅甸语母语教师已完成发音终审**；后续应逐音节校正，尤其zh/ch/sh、j/q/x、-an/-ang、-en/-eng和四声。

## 示例

- 我想租房。 → `wǒ xiǎng zū fáng` → `ဝေါ ရှျန်း ဇူ ဖန်း`
- 师傅下午到。 → `shī fu xià wǔ dào` → `ရှီး ဖူ ရှျာ ဝူ တောင်`
