# Talkami 中缅口语卡片教材统一编写规范 V2

## 教学目标
为中文零基础至初级的缅甸学习者制作手机短句卡片：看一张卡，能理解中文、知道何时对谁说、能自然回应、避免常见误解。不是中文翻译词典，也不是冗长教师讲稿。

2. 日常交往：11–16（26）

4. 吃饭餐饮：21–26、34（23）

## 字段职责
- `text`：中国人会说的自然、高频中文。
- `meaning_my`：准确传达意义、语气、人物关系，不逐字硬译，不滥用 မင်း、ခင်ဗျား、ကျွန်တော်。
- `when_to_use` / `when_to_use_my`：说明真实场景、对象、交际目的，缅文1–3句、足以让初学者独立理解。
- `mistakes`：针对真实的中缅误解、客气话、语气与近义表达区别；没有实质易错点不要凑数，不重复使用说明。
- `alternatives`：自然且意思、语用相近的替换；差异需讲清，不凑数量。
- `replies`：原则上两条自然的上下文回应，中文和缅文一一对应；不是无条件“好的、知道了”。
- `pinyin`：在既有接口支持的主题中使用规范带声调拼音；人名、轻声、变调需复核。
- 原有 `phonetic_my` / `breakdown` 等字段若存在则按既有schema修订，不擅自扩展schema。
- 课程 `opening` / `subtitle` / `level`：明确本节任务、准确卡数与原分级。

## 强制规则与五轮审核
1. 保存原始schema、ID、课序、句序、权限相关字段和已有卡片，不因润色删除。
2. 逐句核查中文是否高频自然且符合人物关系、礼貌程度。
3. 逐句核查缅文是否自然、准确、无乱码、并与中文逻辑对应。
4. 检查“何时用”和“注意”不重复，类似说法可替换、常见回应能接上前句。
5. 跨卡检查重复、混淆和冲突；程序检查JSON语法、数量、字段类型、稳定ID、课次映射。
6. 有实质问题直接修复，不强行给合格内容加长篇说明；不能冒充缅语母语教师终审。
7. 一个完整主题一批，完成后交付完整可用的JSON与简短报告。源文件保持原schema，网站发布文件按既有转换结构生成。

质量样本：主题01的v9 73张卡仅供参考教学深度，不能照抄讲解篇幅或语句。
